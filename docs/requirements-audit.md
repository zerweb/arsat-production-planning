# Сопоставление с техническими заданиями

Проверено 21.10.2026 по `papka/ТЗ_ПЛАНИРОВАНИЕ_ПОРТФЕЛЬ_ЗАКАЗОВ_УДИУ_с_корр_УСТПиН.docx` и трём приложенным фотографиям ТЗ на автоматизированную технологическую подготовку производства. Статус «частично» означает, что отдельные действия работают, но весь описанный процесс и все поля пока не закрыты. Это не акт приёмки по ТЗ.

| Требование | Статус | Проверенное состояние и недостающая часть |
| --- | --- | --- |
| Клиент-серверная архитектура, Windows 10/11, PostgreSQL/MS SQL | Частично | Django/Waitress и PostgreSQL 14 работают локально на Windows; MS SQL и Linux не проверялись. |
| 13 рабочих мест и распределение ролей 1+10+2 | Частично | Роли и проверки доступа есть; испытание одновременной работы 13 сотрудников и отдельные рабочие места нормировщика не проводились. |
| Справочники, заказы, изделия, маршруты, сотрудники | Частично | Вкладки «Операции», «Персонал» и «Табель» теперь обновляют `OperationDefinition`, `Employee` и `TimesheetEntry`; операция связана с маршрутом, а табель с сотрудником и месяцем. Старые строки `LegacyTable` сохранены для совместимости и мигрированы. Отдельных справочников профессий, единиц измерения и всех статусов нет. |
| Портфель заказов и история исправлений | Частично | Редактор «Списка изделий» добавляет, меняет и удаляет строки; количество чертежей и объект сохраняются в `OrderItem` и отображаются в портфеле. Создание/исправление/удаление позиции, сроки, статус, журнал действий и общий поиск работают. Полная фильтрация по каждому перечисленному в ТЗ признаку отсутствует. |
| Годовая, квартальная и месячная программа, версии, мощности | Частично | Годовой, План А, План Б, редакции и расчёт часов есть; месячная программа и полная проверка мощности по календарям/персоналу отсутствуют. Четыре числовые настройки плана сохраняются, но не включены в расчёт. |
| ПЗ, факт, выпуск, качество | Частично | ORM-модели заданий, движения, контроля и ограничений связаны; сквозной сценарий и печать ПЗ тестируются. Не все предусмотренные ТЗ статусы и маршруты согласования доступны в старом интерфейсе. |
| Материалы и КИМ | Частично | Остатки, локальные потребности, импорт выгрузок CSV/JSON/XLSX и расчёт геометрии заготовки доступны. Прямое резервирование через 1С ERP отсутствует. |
| Аналитика, KPI и отчёты | Частично | Пять отчётов, XLSX/ZIP и основные показатели доступны. Конструктора отчётов, всех графиков и проваливания из сводной формы в первичные записи нет. |
| Формы ЕСТД по фото | Частично | Маршрутная карта для детали теперь формируется из связанных записей по структуре формы 1 ГОСТ 3.1118-82: строки М01/М02, А/Б/О/Т, материал, заготовка, оборудование, оснастка и время. Поля редактируются в интерфейсе. Это черновик: корпоративные обозначения, подписи и нормоконтроль не оформлены; форма 2 для сборки, операционные карты и прочие документы требуют отдельной сверки и доработки. См. `docs/estd-gost-3.1118.md`. |
| Расчёт режимов резания и норм по фото | Частично | Модель `CuttingNorm` хранит источник, материал, инструмент, скорость, диаметр, подачу, число зубьев и проходы. Автоматически рассчитываются обороты, минутная подача и машинное время; утверждённая норма влияет на плановые часы. Утверждённых нормативных значений предприятия нет, вводить их как достоверные тестовые данные нельзя. |
| Заимствование типовых/групповых ТП по фото | Частично | Копирование маршрута изделия доступно в ORM-формах; каталог типовых и групповых ТП не выделен. |
| NX CAM 21: структура операций, режимы, УП, карты наладки | Отложено | Пункт скрыт по предыдущему требованию пользователя. Автоматический обмен и связь файлов УП с операциями не реализованы. |
| Оптимизация расстановки персонала | Частично | Автоназначение задания выбирает сотрудника нужного подразделения и разряда с доступными часами с учётом табельной неявки и занятых заданий. Это детерминированное правило для одного задания; глобальная оптимизация портфеля и утверждённые ограничения смен/календарей не определены. |
| Алгоритм контроля по СТО 086-408 | Не подтверждено | В DOCX есть ссылка на стандарт без самого алгоритма; нельзя подтвердить соответствие конкретным шагам стандарта. |
| Установка, поддержка 12 месяцев, обучение | Организационное требование | Код проекта сам по себе не подтверждает поставку услуг и сертифицированного обучения. |

Проверка целостности: тесты проверяют связи маршрута со справочной операцией, табеля с сотрудником, назначения исполнителя с квалификацией, позициями заказа и режимами резания. Миграция `0008` переносит имеющиеся строки старых вкладок в ORM, `0010` создаёт справочные операции из существующих маршрутов, `0011` добавляет поля маршрутной карты. Полное соответствие двум ТЗ по-прежнему не подтверждено: нужны остальные формы ЕСТД и правила их утверждения, нормативные значения, алгоритм СТО 086-408, формат NX CAM 21 и приёмочные критерии для 13 рабочих мест и сопровождения.
