# Проверка функций интерфейса

## Дополнение от 26.10.2026: маршрутная карта ЕСТД

Введены связанные поля материала и операций для черновой маршрутной карты по ГОСТ 3.1118-82. API проверяет допустимые значения и права на изменение, PDF получает данные из ORM. Демонстрационная карта напечатана из временных учебных записей и визуально проверена; длинный маршрут из 25 операций занимает семь листов с повторяемым номером листа. После перехода тестов на обезличенные фикстуры полный прогон `python manage.py test production --verbosity 0` завершился успешно: 59 тестов. См. `docs/estd-gost-3.1118.md` для границ применения стандарта.

Проверка проведена 21.10.2026 на Django 5 и PostgreSQL с демонстрационными данными. Команда `python manage.py test production --verbosity 0` завершилась успешно: 47 тестов. Проверены ответы всех 21 HTML-страниц, маршруты получения данных, создание и изменение основных моделей, права ролей, резервная копия PostgreSQL и сквозной путь заказа. `python manage.py check` и `makemigrations --check --dry-run` также прошли. Headless Edge проверил окно «Изменить список изделий» при 756 и 1200 пикселях, добавление и удаление строки и перенос пяти полей обратно в форму.
