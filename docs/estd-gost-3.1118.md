# Маршрутная карта ЕСТД: ГОСТ 3.1118-82

Дата сверки: 26.10.2026. [Карточка ГОСТ на официальном портале Росстандарта](https://protect.gost.ru/gost/details/11e71aab-c940-4221-97e1-498eb2563f31) указывает статус «Действует». Стандарт устанавливает формы и правила оформления маршрутных карт при изготовлении или ремонте изделий. Из ТЗ на автоматизацию технологической подготовки производства взято требование автоматически формировать маршрутные карты ЕСТД.

## Что реализовано

Для маршрута изготовления детали используется структура формы 1 и последовательность строк `М01`, `М02`, `А`, `Б`, `О`, `Т` по разделу 3.11 и таблицам 3–4 стандарта. Данные берутся из `Product`, `OrderItem`, `RouteOperation`, связанных справочников оборудования и операции. Карта открывается из записи заказа и из списка изделий; по заказу отображается объём партии.

| Строка | Источник данных |
| --- | --- |
| М01 | Обозначение материала по КД (`Product.material_specification`) |
| М02 | Код материала, единица измерения, масса детали, норма расхода, вид/размеры/масса заготовки, число деталей из заготовки; КИМ рассчитывается как масса детали / масса заготовки |
| А | Цех, участок, рабочее место, номер и название операции, ссылки на документы |
| Б | Оборудование, профессия, разряд, число исполнителей, одновременная обработка, партия, подготовительно-заключительное и штучное время |
| О | Содержание операции |
| Т | Технологическая оснастка |

Поля материала открываются кнопкой «Материал ЕСТД» в списке изделий. Поля операции находятся в раскрываемом блоке «Поля ЕСТД» редактора технологического процесса. Время, хранящееся в часах, выводится в карте в минутах. PDF формируется сервером по адресу `/products/<id>/route.pdf`; для привязки к партии используется параметр `item=<id позиции заказа>`.

Черновой PDF создаётся по маршруту конкретного изделия в работающем приложении; тестовые данные для проверки печати находятся в `database_import/`.

## Границы соответствия

PDF помечен как проект. Если материал, оборудование, текст операции, коды рабочего места или партия не заполнены, карта показывает перечень пробелов. Форма повторяет состав и порядок строк формы 1, но не является утверждённым бланком предприятия: нет обозначения технологического документа, подписей, нормоконтроля и полного комплекта листов. Для сборки стандарт предусматривает форму 2; она ещё не реализована. Операционные карты, ведомость оснастки и комплектовочная ведомость требуют отдельной сверки со своими стандартами ЕСТД. Поэтому выпуск карты как официальной производственной документации требует проверки и утверждения технологической службой предприятия.
