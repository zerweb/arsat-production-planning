# Развёртывание и обслуживание

`install.sh` предназначен для Debian, Ubuntu и Astra Linux с APT и systemd. Из Git-каталога проекта выполните `sudo bash install.sh`. Однострочная загрузка из `https://github.com/zerweb/arsat-production-planning.git` через `bootstrap.sh` приведена в корневом README.

Установщик предлагает локальную PostgreSQL либо подключение к существующей БД. Миграции применяются автоматически. Дополнительный Bash-скрипт `database_import/import.sh` загружает тестовые фикстуры только в пустую базу. В фикстурах нет рабочих паролей; первый администратор получает новый случайный пароль, сохранённый в `/root/avt-initial-admin.txt` с правами `600`. После входа смените пароль и удалите этот файл.

Для сетевого доступа установщик требует TLS-сертификат и ключ. Без них Nginx слушает только локальный интерфейс. Служба `avt` запускает `tools/serve.py`: управляющий процесс следит за Waitress, обновляет подключение после изменения `.env` в админке и выполняет восстановление БД только при остановленном веб-процессе.

Команды обслуживания:

```bash
sudo systemctl status avt
sudo journalctl -u avt -f
sudo nginx -t
sudo systemctl restart avt
curl -H 'X-Forwarded-Proto: https' http://127.0.0.1:8001/health/ready/
```

В администрировании можно проверить PostgreSQL, создать или скачать SQL-копию, скачать `.dump` и восстановить архив через управляющий процесс. Перед восстановлением создаётся страховочная копия в `.backups/`. Храните копии также вне сервера. Каталоги `.backups/`, `.runtime/`, локальная PostgreSQL, `.env` и первый пароль не публикуются в Git или Nginx.

Обновление: сначала сохраните внешнюю резервную копию БД, затем `git pull`, обновите зависимости из `requirements.lock.txt`, выполните `python manage.py migrate --noinput` и `python manage.py collectstatic --noinput`, после чего `sudo systemctl restart avt`. Установщик не перезаписывает существующий `.env` и не очищает базу при повторном запуске.

Тестовый прогон до публикации: `python manage.py check --deploy` и `python manage.py test production`. Импорт в пустую тестовую БД проверен автоматическим тестом. Полный прогон установки на целевой Linux-системе требуется перед промышленным вводом.
